## 🎯 API 端點覆蓋

### GET `/api/v1/StudentPayment/ByStudent/{studentId}`

**功能覆蓋**：
- ✅ 查詢指定學生的所有繳費紀錄
- ✅ 返回完整的繳費詳情
- ✅ 包含課程、老師、時間、教室等相關信息
- ✅ 支援排序和過濾

**場景應用**：
- 學生查看自己的繳費歷史
- 管理員查看學生繳費情況
- 財務報告生成
- 繳費對賬

---

### PUT `/api/v1/StudentPayment/Rebind`

**功能覆蓋**：
- ✅ 將繳費記錄重新分配到其他課程費用
- ✅ 支援當日內的繳費重分配
- ✅ 自動處理舊費用上的舊 Payment 記錄
- ✅ 完整的稽核追蹤

**場景應用**：
- 糾正繳費誤屬
- 課程調整後的繳費重分配
- 繳費糾正
- 金額變更後的重新分配

## 📞 技術支持

### 常見問題解答

1. **API 返回 401** → 檢查 Token 是否有效
2. **無法找到繳費記錄** → 確認 studentId 和記錄狀態
3. **換綁失敗** → 檢查時間和目標費用狀態
4. **測試工具無法載入** → 清除瀏覽器緩存
